# BiliSmooth 2.8.2 · 首个公开版本 / First public release

BiliSmooth 是面向海外 B 站网页观看的 Chrome / Edge 播放辅助扩展，把下载速度、按倍速换算的可播余量和 CDN 控制放进视频页浮窗。

BiliSmooth is a Chrome / Edge playback helper for overseas Bilibili viewers, with live download speed, playback-rate-adjusted buffer time, and CDN controls in an in-page floating panel.

## 本版功能 / Highlights

- 可拖动、贴边的三态浮窗，自选常驻指标；独立仪表盘提供下载曲线、线路管理和运行记录。
- 自动或固定 CDN 选线，以及基于真实播放反馈的卡顿恢复；保留播放器选择的画质。
- 9 个自动候选，包含 `upos-sz-mirrorhwb.bilivideo.com`。
- 中文／英文界面、明暗主题、本地偏好和手动诊断导出。
- Draggable floating controls, an independent dashboard, automatic or fixed CDN selection, local preferences, and Chinese / English interfaces.

## 下载与安装 / Installation

1. 下载附件 **`BiliSmooth-2.8.2.zip`**，不要把自动生成的 Source code ZIP 当作安装包。
2. 解压并保留文件夹；打开 `chrome://extensions` 或 `edge://extensions`。
3. 开启开发者模式，选择“加载已解压的扩展程序”，选中含 `manifest.json` 的文件夹。
4. 刷新 B 站视频页。

Download the attached **`BiliSmooth-2.8.2.zip`**, extract it, enable Developer mode in Chrome / Edge's extension manager, choose **Load unpacked**, and select the folder containing `manifest.json`. Refresh Bilibili video pages. Requires Chrome / Edge 120+.

`SHA256SUMS.txt` 包含本次构建安装包的 SHA-256。升级时替换原安装目录的内容，重新加载扩展并刷新视频页。
