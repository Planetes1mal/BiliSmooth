# 中文商店介绍

## 名称

BiliSmooth - B站播放助手

## 简短描述

切换 B 站视频 CDN，在浮窗中查看下载速度、可播时长和播放状态。

## 详细介绍

看 B 站遇到慢线路时，用 BiliSmooth 选择其他播放线路。小浮窗会显示下载速度，以及按当前倍速计算的可播余量。

扩展读取当前 B 站页面的标题、地址、播放信息和媒体地址，用于显示状态及选线。分析和设置保留在浏览器中。播放和线路探测会连接 B 站及 CDN，服务器会收到 IP 地址和媒体签名地址；兼容中转服务还会收到原始媒体地址。扩展没有开发者遥测或自动诊断上传。

主要功能

• 在视频页面查看播放状态、下载速度和可播余量。
• 自动选择播放线路，也可以手动固定线路。
• 卡顿时尝试其他线路，可开启自动恢复。
• 在独立控制面板中调整播放设置、选择视频标签页。
• 支持中文和英文、浅色和深色，以及浮窗位置和指标设置。

如何使用

打开 bilibili.com 上的视频。鼠标移到 BiliSmooth 边缘小条上查看指标，点击展开播放控制。点击浏览器工具栏中的扩展图标，打开独立控制面板。如果安装前已经打开视频页，请刷新一次。

BiliSmooth 无需单独注册账号，B 站原有的账号与内容要求仍然适用。扩展保留你选择的画质，不解锁付费画质或受限视频。可用线路取决于网络和视频。
