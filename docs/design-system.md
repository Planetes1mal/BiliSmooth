# BiliSmooth 设计规范

界面使用几何播放标志、圆角浮窗及顶部分页仪表盘，以雾白、墨灰与青碧作为默认配色。浮窗与仪表盘读取同一播放会话；文档示意图中的演示数据不进入实际播放状态。

## 视觉基础

共享样式位于 `src/ui/surface.js`，入口和状态图形位于 `src/ui/entry-display.js`。

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 页面 / 卡片 | #F5F7F6 / #FFFFFF | #191D1B / #232825 |
| 文字 / 辅助文字 | #1F2925 / #5B6861 | #EEF3F0 / #ACB9B1 |
| 青碧色面 / 配对文字 | #D8EAE3 / #244D44 | #2D443A / #D3E9DD |
| 边界 | #D9E1DC | #3C4941 |
| 强调文字 / 焦点 / 曲线 | #2F6D60 | #9CCCB7 |

主要按钮和开关采用中性深浅色，数值采用正文字色与等宽数字。正文、状态与控件的字重高于旧版。保留已有强调色偏好，新配置默认青碧。仅使用本地字体回退，不加载远程字体或界面脚本。

八种强调色使用一致明暗层级的低饱和色面。深色以墨灰保持层次，不反转成亮色入口。入口使用独立的 `--entry-bg/ink/muted/border` 与 `--shadow-entry`；文字、图标和色面成对验证，状态色不叠加会损害识别的整体透明度。正文按 4.5:1、承载信息的图形按 3:1 检查实际合成颜色。

几何标志在入口、仪表盘、SVG 与 16/32/48/128px 扩展图标中一致。构建比较内联与文件 SVG 的形状，资源名带内容哈希。通用图标沿用 Tabler outline 及其 MIT 许可。

## 浮窗状态和位置

默认三态 `edge → preview → panel`。关闭“显示入口”后最小状态是 preview；离开、外部点击、Esc、新视频、刷新和退出全屏均遵循该最小状态。网页全屏、原生全屏及隐藏文档仍隐藏交互层。

- 入口默认 54px 高的圆角状态 logo。悬停稍作延迟进入预览，鼠标点击可直接进入面板；触屏首次点击进入预览。
- 预览目标宽 256px，显示状态动画与独立选择的状态文字、速度、可播余量；点击进入面板。
- 面板目标宽 312px，包含状态动画、两列指标、优化开关、真实当前请求、后续线路选择、重新评估、切换备用和大尺寸“打开仪表盘”。窄视口按可用空间收窄，超高内容内部滚动。
- 入口、整个预览及面板标题均可拖动。方向键移动、Shift 加速、Home 复位；位置菜单提供四角和复位，仪表盘也可重置所选视频的浮窗位置。

三态共用角点锚点。拖动完成时按所在半区选择左右/上下锚边；展开和收起使用同一锚点，不再次寻找其他角落。坐标以 v3 本地位置记录保存。初始自动位置优先避开已知播放器和控件；用户的自由位置只按可用视口限制。空间不足时就近约束位置和尺寸，不能为旧版避让规则把它跳到另一个角落。

所有边界使用 `shared.viewport(window)`：fixed 标记与 visualViewport 的交集，保留 originX/Y 和 scaleX/Y 换算。四周安全内边距为 8px，不能将滚动条、双侧 gutter 或 body 宽度当成可用面积。

拖动始终跟手；距离安全边缘 24px 内出现淡色落点提示，松手才轻吸附。提示不截获指针。落位使用短促、强阻尼的 Motion spring；下一次按下立即从当前视觉位置接管。关闭吸附后保留自由位置。

## 九种入口内容

`floatingEntryType` 支持 `status-logo`、`logo`、`status`、`speed`、`buffer`、`combined`、`route`、`rate`、`resolution`。设置中每张选项直接展示所选视频的实时结果，且与 `floatingFields` 的预览偏好独立。指标宽度固定，避免数值更新引起尺寸和位置抖动。

播放投影来自共享 `projectPlayback`。只有近期、可见且健康的画帧证据才表达顺畅。缓冲、画面停滞采用不同运动；暂停、结束、待检测等保持相应静态标记。无有效样本显示“—”，有效零值仍为零；速度使用真实 Mbps 转为十进制 MB/s / KB/s，余量按实际倍速换算，分辨率来自实际 video 高度。

状态 logo 的顺畅态为两段相对横向流动，缓冲态上下分开等待，卡顿态短促受阻后停顿，暂停态在中部显示两道静态暂停线。不可用细微亚像素运动充当唯一状态区别。系统减少动态效果、后台与关闭动效继续停止循环。

速度按完整三秒观察窗口统计吞吐，包含已确认持续监测的空闲零值；以 `speedObservedAt` 判断数值有效期。未知、离线、长监测间隔及切换视频保留未知。曲线按真实时间戳绘制，单个观测保留可见点，缺失区间断开；不能将旧速率重复成平台，不能用虚构样本平滑曲线。

## 仪表盘和日志

仪表盘使用顶部导航。概览左侧为两项数据和下载曲线，右侧为真实视频卡片；播放状态在视频属性中呈现，不再添加宽状态条或重复动画区。保留视频来源选择、线路证据、手动域名、开播/恢复摘要和诊断功能。

偏好设置先展示完整入口预览，再分组排列播放恢复、MCDN/P2P 等兼容性、浮窗动效与预览字段、外观与语言。菜单使用共用选择组件，与页面色彩、边框、圆角和动效一致。

九种入口改为紧凑横向选项，实时效果保持 54px 高；桌面三列、平板两列、手机一列。只压缩额外留白和重复说明，不缩小实际预览，不折叠隐藏九种选项；宽屏保留简短说明，窄屏仍提供可访问的说明关系。

运行记录采用固定高度的内部滚动区和细滚动条。“记录类型”和选择器保留清楚间距。新记录在顶部：用户阅读历史时保持已有行和滚动位置，只更新“有 N 条新记录”；点击后增量插入并平滑回到最新。只有新行做轻微过渡，滚轮、触摸和滚动键可打断返回。筛选与清空显式操作更新列表，诊断导出不受当前筛选影响。

## 动效、可访问性与验证

Motion 13.2.0 在构建时本地打包。展开约 390–400ms、收起约 240ms；背景几何与内容分别运动。系统减少动态效果优先，关闭界面动效停止状态动画和过渡。隐藏、销毁和取消手势清理临时状态。

开关只响应轨道或精确关联标签，空白布局不代理点击。按钮保留原生语义与 focus-visible；选择菜单支持方向键、Enter、Esc 和中文组合输入。折叠内容同时 hidden/inert；保存失败提供明确重试，不把播放状态当成保存成功。

验证方式见 [播放与界面验证指南](validation/playback-testing.md)。示意图片中的演示数据不作为性能证据。

## 交互细节

正文以 14px、辅助信息至少 12px 为基准；窄屏优先换行与重排，入口展示保持 54px。现有八种强调色 ID 与 v4 配置记录保留。

入口悬停的视觉层约 260ms 上浮 3px、轻旋 −3°，标志反向轻旋；预览仅上浮及阴影变化。靠近边缘按可用空间缩小动幅，几何锚点不移动。触摸、拖动、关闭动效及减少动态效果不执行悬停装饰。页面切换使用约 390ms 上浮、轻缩放与回弹，实时刷新不重新入场。

选择菜单提供实例与全局 `syncMotion()`。系统偏好、应用开关或可见性要求静止时，立即取消动画并收束到当前逻辑状态；退出时同时隐藏 popover。重新开启动效只影响下一次交互。
